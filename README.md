# Jain Ludo — Path to Moksha

An original, Jain-inspired Ludo-style browser game built with Phaser 3 and
TypeScript. Classic square/cross Ludo board structure, an original two-dice
system (a normal 1-6 Pasa plus a four-face Gati Pasa), fully original
procedurally-generated art and audio, computer bots, and 2/4-player local
play.

## Quick start

```
npm install
npm run dev       # http://localhost:5173
```

```
npm test          # runs the 52-test Vitest suite against the rules engine
npm run build     # type-check + production build into dist/
npm run preview   # serve the production build locally
```

## The core rule you must not misread

The Gati Pasa (Dev / Manushya / Tiryanch / Narak) is **only an entry
unlock**. A **Manushya** result lets the player bring **any one** of their
four Kukri out of the yard - it is not tied to the Manushya-named Kukri.
Any other result brings nothing out. See `GAME_RULES.md` §3.2 for the full,
tested specification.

## Project structure

```
src/core/      Rules engine (no Phaser dependency)
src/bots/      Bot decision-making, calls the same engine API as humans
src/rendering/ Board geometry + procedurally generated textures
src/scenes/    Phaser scenes
src/ui/        Reusable UI components
src/audio/     Synthesized audio (no external sound files)
src/storage/   localStorage settings persistence
tests/         Vitest suite (52 tests)
```
